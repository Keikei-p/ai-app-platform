# 12 Release Gates

本番公開はAI単独で実行しない。以下を順番に通す。

1. Safety Gate
2. 仕様確定 / 対象OS確認
3. 自動テスト
4. セキュリティ検査
5. 個人情報・権限・課金チェック
6. バックアップ / ロールバック確認
7. ストア・地域規約チェック
8. 人間の最終承認
9. 本番公開
10. 公開後ヘルスチェック
11. 異常時ロールバック

## 常に承認必須
- 本番公開
- 本番DB削除
- 課金設定変更
- ドメイン変更
- 秘密情報エクスポート
- 大量ユーザー削除
- App Store / Google Play / Microsoft Store提出

## AIでも実行不可
- Safety Gate無効化
- AI自身の権限昇格
- 監査ログ全消去
- 全バックアップ消去
