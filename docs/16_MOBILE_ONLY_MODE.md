# 16 Smartphone-only Final Mode

PCを持っていない人も同じアプリ体験を使える最終構成。

スマホ -> Control API -> Job Router -> Hosted Worker -> Build/Test -> Preview -> Approval -> Release

PCありユーザー:
スマホ -> Control API -> Home PC Worker

同じJob形式を使い、Workerだけ差し替える。

スマホで完結させる操作:
- 新規アプリ依頼
- 要件確認
- 進捗
- プレビュー
- 修正指示
- テスト結果
- 公開承認
- 保守状況
- 緊急停止
- 課金/プラン確認
