# Home Quick Start - v0.4.8

1. `START.bat` をダブルクリック。
2. Pythonが無い場合だけ `SETUP.bat`。
3. 全検査は `CHECK.bat`。
4. Windows EXE作成は `BUILD_WINDOWS.bat`。
5. 問題時は `DIAGNOSTICS.bat`。

## 通常制作
- 新規プロジェクト
- 制作指示
- Safety Check → 仕様化 → 制作 → テスト
- Code Vaultで保存/履歴/差分/復元

## スマホLAN Remote
- 画面上部 `リモート`
- `同じWi-Fi向けに開始`
- 表示URLをスマホで開く
- `新しいペアリングコード`
- スマホに10文字コードを入力

信頼できるプライベートWi-Fiのみで使用し、ポート開放はしない。

## 更新
- `更新を確認` → `.aipupdate` を選択
- `更新する`
- 更新前バックアップ / 更新後テスト / 失敗時ロールバック
